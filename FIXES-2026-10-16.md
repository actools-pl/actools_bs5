# BOA smoke-test corrections — 16 October 2026

## Corrections

- The Drupal user template reads the actual `elements['#view_mode']`. In compact
  author-picture views it suppresses the profile name heading and action links,
  preserves rendered picture/content, and passes the correct view mode to the
  component. Profile actions remain available outside compact mode. The wrapper
  leaves the profile heading to Drupal's page-title block, preventing a second
  copy of the name. The reusable User component still accepts its own label.
- Removed the Drupal.org `project` field that caused the custom theme to appear
  as having no available releases. Removed the inherited packaging timestamp.
  The source version remains 5.0.0-beta1; this is a dated custom build, not a
  newly certified upstream release.
- Added a Drupal Kernel regression covering the actual user-template wrapper
  for compact and full modes, including retained picture content.

## Apply this small correction to the existing test platform

Back up `templates/user/user.html.twig` outside the web root, then replace that
file with this package's copy. The metadata correction is already present on
the test server; use this package's info file for later clean platform builds.
Clear Drupal caches in Configuration > Development > Performance. Check node/1
and node/2: the extra author heading should be absent while Submitted by remains.
Also check a normal user profile shows one page heading and its permitted actions.

For new BOA platforms, build the complete package before platform registration.
Drupal 11.1+ does not add Body automatically to newly created content types;
create an appropriate text field when setting up test content. Theme settings
and block placement changes are site configuration, not included in theme code.
