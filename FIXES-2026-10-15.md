# Corrected standalone build — 15 October 2026

This ZIP updates the uploaded Actools BS5 5.0.0-beta1 fork and preserves the
machine name actools_bs5. It is not an upstream Vartheme rebase.

## Implemented

- Working linked card titles when no button is requested; normal button links
  retained without duplicate title links.
- Hardened component URL strings, including embedded control characters;
  removed double escaping in button/badge query strings.
- Core filtering for plain HTML strings in place of raw Twig output.
- Safe text summaries with HTML tags removed before trimming, escaped suffixes,
  entity preservation and spacing between standard block elements.
- Corrected native image source normalization, carousel IDs/content/media mapping,
  a runtime/schema carousel component allow-list and sequential indicator indices.
- Corrected reusable navbar ARIA/control relationships, unique IDs, mobile focus,
  block-title properties and authored heading capitalization.
- More useful educational printing: hide page/editor chrome, reveal Bootstrap
  answers/tabs, keep lesson attribution and discourage figure/table splits.
- Six native Layout Builder section layouts with responsive columns and retained
  editor-region attributes. No new content types or block types are installed.
- All 16 Canvas-only image/video schema references replaced with self-contained
  media schemas. Canvas media-picker autodetection is outside this standalone build.
- Token-file cleanup now runs through actual theme execution, once per day with
  locking and seven-day retention. Active/subtheme/newly-used files are protected.
- Better default-surface link/button contrast and conditional primary-font preload.
- CSS builds stage output and block unsafe/stale/tampered publication; exact
  dependency pins and regression tests are included.

## Validation and remaining limits

The static audit passed 27 checks with zero hard failures. One low-severity
advisory concerns demo-image paths for nonstandard theme installation locations.
PHP lint was explicitly skipped. Three layout source checks and nine build-tool
regressions passed. All 113 YAML files parsed with duplicate-key detection.
The build checker parsed all ten maintained stylesheet outputs.

This environment has no PHP/Drupal runtime or Chromium executable, so installation,
Twig rendering, Layout Builder drag/drop, browser accessibility and actual print
pagination have not been certified. Meaningful Drupal Kernel/Functional tests are
included for these behaviors and require a disposable test site. Evidence and
explicit skips are recorded under tests/evidence/; see TESTING.md.

Full reconciliation of the inherited Sass/upstream PostCSS output remains open.
The safe staged workflow prevents accidental replacement of shipped CSS, but is
not a claim that the current slim compiler reproduces it. Actual Sass compilation
could not run here because the locked development dependencies were unavailable.

No live server was changed. After replacing existing theme code, clear Drupal
caches. For the new section choices, enable/configure core Layout Builder and
look under Actools sections. Details are in README.md.
